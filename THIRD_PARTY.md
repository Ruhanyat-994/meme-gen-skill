## memegen

meme-gen sends caption text over HTTPS to the memegen API (default host `api.memegen.link`) and saves the image it returns. It does not bundle memegen's source code.

- Project: https://github.com/jacebrowning/memegen
- Author: Jace Browning and contributors
- License: MIT
- Public service: https://memegen.link (free; the maintainer accepts donations to keep it running)

The curated template list in `skills/meme-gen/references/templates.json` contains template ids and names that exist in memegen's public template catalogue, plus original descriptions and examples written for this project. Template artwork is not distributed here.

meme-gen is an independent project and is not affiliated with or endorsed by memegen.
