# Writing memes that land

A meme works when the picture does half the joke. Pick the template from the *shape* of the joke, then write the shortest text that fits.

| Joke shape | Template ids | Pattern |
|---|---|---|
| Prefer the worse option | drake, pooh | boring-correct / ridiculous-but-real |
| Everything is fine (it isn't) | fine, harold | calm line / the disaster |
| Small cause, huge mess | disastergirl | tiny action / catastrophe |
| Argument | woman-cat | angry complaint / deadpan reply |
| Escalation of bad ideas | gb | 4 steps, last one is absurd |
| Plan backfires | gru | steps 1-2 fine, 3 and 4 both fail |
| Distracted by the shiny thing | db | new thing / me / what I had |
| Bad logic | rollsafe | "can't X if you Y" |
| Tempted | kermit, exit | the right thing / the thing I do |
| Smug sarcasm | wonka | "oh you did X? tell me about Y" |
| Dilemma | ds | two options / sweaty person |
| Hot take | cmm | one claim |

Rules of thumb
- One idea. If you need to explain it, cut it.
- 3-8 words per box, max 12. Cut filler words first.
- The punchline goes in the last box.
- Use details people recognise (the 3 AM page, the Friday deploy, the forgotten cloud bill).
- Use each template at most twice per batch; vary the shapes.
- Plain words beat jargon unless the jargon is the joke.
- Read it aloud. If it does not get a small smile, rewrite or drop it.
